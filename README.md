* 📂 **拒绝重复造轮子**：将枯燥繁琐的现场经验和反复调试的代码沉淀为自动化工具。通过自主开发的上位机和小工具，大幅提升团队工程效率，解放人力。
* 💡 **开放与知识共享**：乐于将实战中的技术积累以开源项目、视频拆解、图文笔记的形式分享出来，与同行一起推进工业与物联网的技术进步。
